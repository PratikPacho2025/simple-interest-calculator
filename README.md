# Simple Interest Calculator

## Description

This project is a simple interest calculator that calculates the simple interest based on the principal amount, annual rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:

- **Principal (P)** = Initial amount of money
- **Rate (R)** = Annual rate of interest
- **Time (T)** = Time period in years

## Example

If:

- Principal = ₹10,000
- Rate = 5%
- Time = 2 years

Then:

**Simple Interest = (10,000 × 5 × 2) / 100**

**Simple Interest = ₹1,000**

## Result

The simple interest is **₹1,000**.

## Purpose

This project demonstrates the basic calculation of simple interest and can be used as a beginner-level programming project.
